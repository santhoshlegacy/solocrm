# Unslop Frontend Design Skill

Eliminate generic "AI-slop" patterns:
1. **No generic gradient blobs**: Replace random purple/blue blobs with intentional, domain-specific ambient forms.
2. **Typography & Hierarchy**: Pair editorial/authoritative typefaces (e.g., Plus Jakarta Sans + Inter) with crisp tabular numbers and strict contrast.
3. **Card Architecture**: Avoid uniform identical cards with random emojis. Provide varied visual weights, bespoke status indicators, and distinct metric treatments.
4. **Micro-interactions**: High-fidelity spring physics (stiffness 300, damping 24), active pill glides, specular rim highlights, and intentional hover states.
5. **Authentic Domain Copy**: Zero placeholder "Lorem Ipsum" or generic marketing fluff. Use realistic domain data (MRR, retainers, liquidity vaults, billable rates).
